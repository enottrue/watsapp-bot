# Настройка Битрикс24

## Важно о безопасности

**`client_id` и `client_secret` - это конфиденциальные данные!**

- Храните их только в файле `.env` (не коммитится в git)
- Никогда не передавайте эти данные третьим лицам
- Файл `.env` добавлен в `.gitignore`

---

## Способ 1: Входящий вебхук (проще)

1. Зайдите в ваш портал Битрикс24: `https://ваш-портал.bitrix24.ru`
2. Перейдите: **Приложения** → **Вебхуки** → **+ Добавить вебхук**
3. Выберите права доступа:
   - `CRM` - для работы с контактами и сделками
   - `Пользователи` - для получения информации о пользователях
   - `im` - для работы с чатами и открытыми линиями
4. Нажмите **Сохранить**
5. Скопируйте URL вебхука:
   ```
   https://ваш-портал.bitrix24.ru/rest/1/abc123tokenxyz/
   ```
6. Извлеките токен из URL (часть после `/rest/1/`):
   ```
   Токен: abc123tokenxyz
   ```

**Настройте `.env`:**
```env
B24_DOMAIN=ваш-портал.bitrix24.ru
B24_ACCESS_TOKEN=abc123tokenxyz
```

---

## Способ 2: REST API приложение (полный доступ)

1. Перейдите: **Приложения** → **Интеграции** → **+ Добавить приложение**
2. Заполните форму:
   - Название: `WatsApp Integration`
   - Права: `CRM`, `Пользователи`, `im`, `Чат и звонки`
3. Нажмите **Сохранить**
4. Скопируйте:
   - **Код приложения (client_id)**
   - **Ключ приложения (client_secret)**

**Настройте `.env`:**
```env
B24_DOMAIN=ваш-портал.bitrix24.ru
B24_CLIENT_ID=ваш_client_id
B24_CLIENT_SECRET=ваш_client_secret
```

> Примечание: Для REST API приложений также потребуется получить `access_token` через OAuth авторизацию. Рекомендуем использовать **Способ 1** для простоты.

## Настройка переменных окружения

Откройте файл `.env` и заполните:

```env
# === Битрикс24 ===

# Домен вашего портала (без https://)
B24_DOMAIN=ваш-портал.bitrix24.ru

# ВАРИАНТ 1: Токен из входящего вебхука
B24_ACCESS_TOKEN=токен_из_url_вебхука

# ВАРИАНТ 2: Данные REST API приложения (опционально)
B24_CLIENT_ID=ваш_client_id_из_настроек_приложения
B24_CLIENT_SECRET=ваш_client_secret_из_настроек_приложения
```

## Проверка подключения

```bash
curl http://localhost:3000/api/bitrix24/test
```

Успешный ответ:
```json
{
  "success": true,
  "user": "Иван Иванов",
  "domain": "ваш-портал.bitrix24.ru"
}
```

Ошибка (не настроено):
```json
{
  "success": false,
  "error": "B24_DOMAIN или B24_ACCESS_TOKEN не настроены"
}
```

## API эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/bitrix24/test` | Проверка подключения |
| GET | `/api/bitrix24/user` | Текущий пользователь |
| GET | `/api/bitrix24/connectors` | Список коннекторов |
| GET | `/api/bitrix24/openlines` | Открытые линии |
| GET | `/api/bitrix24/apps` | Список приложений |

## Примеры использования

### Получить список коннекторов

```bash
curl http://localhost:3000/api/bitrix24/connectors
```

### Получить открытые линии

```bash
curl http://localhost:3000/api/bitrix24/openlines
```

### Получить информацию о пользователе

```bash
curl http://localhost:3000/api/bitrix24/user
```

## Устранение ошибок

| Ошибка | Решение |
|--------|---------|
| `fetch failed` | Проверьте `B24_DOMAIN`, убедитесь что портал доступен |
| `permission denied` | Проверьте права вебхука/приложения |
| `Invalid token` | Проверьте `B24_ACCESS_TOKEN` в `.env` |
| `B24_DOMAIN не настроен` | Добавьте домен в `.env` файл |
